# stash.cool, "The Stash" index (`?cat=cataloging`)
**What it is:** a resource directory (not blog posts), but the list pattern would suit posts. Section bar: "The Stash" with a count (9), a Category dropdown, a Sort dropdown, and a Search box (`/` to focus). Columns: number, name (a yellow dot marks "New this month"), one-line description, domain in monospace, an external arrow, and a plus.
**Each row is one real link** (`<a class="row" href="/index/cosmos/">`) containing the number, name, category, description, domain, and a hidden lazy-loaded screenshot (`.c-shot`, `aria-hidden`, not displayed at rest). The pages are pre-rendered static HTML; the JavaScript takes over for filtering, sorting, and search.
**Hover (pure CSS, measured):** a black fill wipes outward from the vertical center of the row (`clip-path: inset(50% 0)` to `inset(0)`, 0.35s, `cubic-bezier(.7, 0, .2, 1)`), the text turns white, and every column except the plus slides 8px right. The same effect fires when you hover the external-arrow link in the row, and for the keyboard cursor (`.is-cursor`).
**Click:** the whole row, including the plus, navigates to a detail page (`/index/cosmos/`); the plus did not expand in place. The detail page is styled like a catalog record (RECORD, TITLE, CLASS, LOCATION, NOTES), with a breadcrumb ("Index / Cataloging / 003 Cosmos"), "3 of 9 in Cataloging", previous/next arrows, a framed preview of the site, and a related-items list.
**Cross-page transitions:** `@view-transition { navigation: auto }` plus a persistent site header (`view-transition-name: site-head`) and a 0.2s fade-in for the new page. This is a CSS feature that makes a multi-page site feel like one continuous space, without a single-page app.
**Keyboard layer (`keys.js`):** ⌘K or Ctrl K opens a command palette that searches every item, article, and category and can switch theme; `?` shows a shortcut card; J/K next/previous; O opens the site; G then H/I/A goes Home/Index/Articles; 1-9 jumps to a category; `/` searches the index; arrows and Enter move through the list. The comments say the whole layer can be removed by deleting one script line.
**Category URLs:** `?cat=` on the home page, and `/index/<category>/` pages elsewhere, so each filter has a shareable address and Back works.
**Motion control:** a "Pause all motion" button sits bottom left (plus a play/pause for each video).
**Other motion (read from source comments, not seen):** the wordmark is built from tiles that fall and stack on load and lift away on scroll; a small red character (a video recombined with its alpha mask on a WebGL canvas) walks over the wordmark once and plays another take when it's clicked; it does nothing under reduced motion or if you arrive scrolled down. The site's own comments say "No scroll-jacking."
**Not examined:** the dropdowns, sort, and search in action; the palette; the preview frame on the detail page; the hero animation itself.
